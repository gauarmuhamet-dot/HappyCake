# Happy Cake Website

## Project Description
Happy Cake is a bakery website created using HTML5.
The website provides information about cakes, prices, bakery details and an order form.

## Pages Included
- index.html - Home page
- menu.html - Cake menu and prices
- contact.html - Contact information and order form
- colophon.html - Website development information

## Technologies Used
- HTML5
- Visual Studio Code

## Validation
All HTML files were tested using W3C Nu HTML Checker.
No errors or warnings were found.
